# 直播问答

1. 每次进入直播模式创建独立会话；系统声音和麦克风转写按时间追加，不能用新文字覆盖旧记录。
2. 系统声音通常是观众问题，麦克风通常是主播发言。来源必须保留，不能把两者混成一条消息。
3. 原始转写必须原样记录。可以在内部结合上下文处理同音字、漏字和断句，但不把猜测写回原始记录。
4. 每个系统问题对应独立回答；回答流式更新时只能更新自己的记录，不得替换其他问题的回答。
5. 输出优先短、自然、适合口头表达的中文。无法确定时用条件化表达或请求澄清，不要编造确定结论。
6. 新回答要参考本次会话已有的问答风格，但不能把之前的推测升级成事实。
