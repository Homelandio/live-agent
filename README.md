# 直播智答 MVP

一个本地优先的 Electron 直播辅助 Agent：Codex 风格对话、文件知识库、语音转写、第三方 OpenAI-compatible API 和 Windows 内容保护提词窗口。

## 运行

```powershell
npm install
npm start
```

## 当前范围

- 麦克风和系统声音统一通过本地 FunASR 转写；麦克风使用本地采集与语音活动分段，不依赖浏览器在线 SpeechRecognition 或语音 API Key。
- 系统声音入口使用 Windows 显示器音频捕获，支持“手动截断模式”和“实时流式模式”。前者由用户开始/结束完整录题区间后统一转写，后者按语音停顿自动分段并按顺序提交；问答 API 只负责生成回答。
- API 使用 OpenAI-compatible Chat Completions 格式。
- API 地址既可填写服务商基础地址（例如 `https://example.com/v1`），也可填写完整的 `/chat/completions` 地址；设置面板的“获取模型”会请求同一基础地址下的 `/models`，返回的模型可通过下拉列表切换。
- 连接方式支持自定义 OpenAI-compatible 接口、OpenAI 官方 API、`OPENAI_API_KEY` 环境变量、本机 Ollama 和自动检测；“测试连接”会区分网页地址、鉴权失败、接口路径错误、限流和网络超时。
- API 请求由 Electron 主进程代理，避免渲染层跨域限制；环境变量模式不会把 Key 写入知识库或本地配置。
- 最近对话会持久化并可恢复；知识库文件、长期记忆支持查看和删除，知识库可导出 JSON 备份并在本地恢复。
- 直播转写支持麦克风和系统声音两条路径，并使用短停顿容忍、最长段长保护的连续语音分段。每次进入直播模式都会创建独立会话，左侧按来源保留系统声音问题和麦克风发言，右侧按问题保留独立回答，主界面和悬浮窗都支持上下滚动查看。
- 原始转写永远保留，不由大模型回写覆盖；回答模型会在内部结合本次会话、知识库和网络资料处理同音字、漏字和断句歧义，无法确定时会明确保留不确定性。
- 当本地资料和长期记忆都没有相关匹配时，可选调用 DuckDuckGo Instant Answer 做公开网络补充；搜索只发送当前问题，结果会带来源链接并与个人上下文分开标注。
- 直播模式会隐藏主窗口任务栏图标并只保留受内容保护的半透明提词窗；提词窗可直接提问、截图、清空、切换自动回答、查看来源、关闭直播或退出软件。
- 悬浮提词窗提供麦克风和系统声音两个独立切换开关，状态会与主界面双向同步，并显示关闭、准备中、重连中或开启状态。
- 悬浮提词窗设置内可切换系统声音采集模式；选中状态、主界面下拉框和本地持久化配置保持同步，采集过程中切换会被阻止以避免丢失音频。
- 直播模式会在主屏幕左下角显示独立的快捷键提示层；它使用透明受保护窗口、不可点击且不进入任务栏，快捷键表随主悬浮窗的背景透明度和文字透明度即时同步。
- 悬浮提词窗取消系统拖动区域，支持在显示设置中即时吸附到屏幕上、右、下、左侧，避免拖动透明窗口时出现录制可见的系统边框。
- 悬浮提词窗收起时会缩为约 `260×45` 的窄栏，只保留“展开”和“结束”；再次展开恢复完整面板。
- 直播期间提供低冲突快捷键：`Ctrl+Alt+Shift+R` 系统声音开始/截断，`H` 收起/展开，`P` 循环位置，`S` 截图，`Enter` 发送截图，`Backspace` 删除截图；退出直播后自动注销。
- 主界面“操作设置”支持逐项录制和保存直播快捷键；按键组合保存在应用 `userData/live-shortcuts.json`，至少需要两个修饰键，内部重复会阻止保存，直播注册失败会显示为被占用。恢复默认不会影响知识库、记忆或 API 配置。
- 悬浮提词窗始终启用 Electron/Windows 内容保护，并在窗口生命周期和位置切换时重复施加；该机制对尊重 Windows 显示排除标记的录屏有效，但无法保证对忽略系统标记的驱动级捕获或摄像机绝对不可见。
- 支持 TXT、MD、JSON、PDF、DOCX 导入；文本会在本地按段落边界切分，并使用 BM25 风格词项频率/稀有度、短语命中、文件名命中、查询覆盖率和相似片段去重进行混合检索，尽量保留跨文件证据。
- 支持授权工作区目录：在设置中添加文件夹后，普通对话会在回答前自动检索其中的 TXT、MD、JSON、CSV、PDF 和 DOCX，并把跨文件命中内容按 `工作区/文件名` 标记送入模型；授权目录保存在 `userData/workspace.json`，不会写入仓库或自动上传。
- 支持在受保护悬浮窗中自动截取当前主屏幕，先预览为截图草稿，用户可删除或发送；发送时向兼容视觉模型提交图片内容。悬浮窗依赖 Windows 内容保护排除自身，不能保证对忽略系统保护标记的捕获方式绝对不可见。
- 直播快捷键截图会直接写入悬浮对话框草稿，不经过主界面渲染层，不打开摄像头，也不会在截图完成后抢回游戏或其他窗口焦点；截图期间会暂时隐藏问答窗和左下角快捷键提示层，避免它们出现在截图中。
- Chat Completions 支持 SSE 流式回答，非流式响应也能回退处理。
- 独立提词窗口支持收起、滚动、退出和 Electron 内容保护。
- 知识库和长期记忆持久化到稳定的 Electron `userData/vault.json`，应用更新不会覆盖；每次写入前额外保留 `vault.json.bak`，主文件损坏时自动恢复上一份有效数据。
- 每轮用户消息会尝试提取用户明确陈述的稳定事实或偏好，写入长期记忆；只保存用户消息，不从助手回答反推。
- `setContentProtection(true)` 启用 Electron/Windows 内容保护，尽量排除 OBS 显示器或窗口采集；它不是绝对 DRM，必须实际测试采集方式。
- 系统回环音频采集需要在 Windows 共享选择器中选择带声音的窗口或显示器，仍需结合具体音频设备和 OBS 场景验证。
- DeepSeek 等兼容接口只负责文字问答；语音通过可替换的转录提供者协议接入，默认实现是 `FunASR Paraformer 中文流式（本地）`。
- FunASR 的服务脚本和提供者清单位于 `resources/transcriber`；源码仓库不提交 Python 运行时和模型权重，发布构建会打包构建机已有的资源，用户也可以按上游许可下载替代模型，或使用外接 HTTP 提供者，不需要修改渲染层。
- FunASR 进程只在软件运行期间存在；正常退出会清理整个转录进程树。模型文件保留在磁盘，不会在退出后继续占用内存；强制终止或断电等异常场景可能需要人工检查残留进程。
- Agent 工作流支持本地 `SKILL.md`：内置事实约束、知识库检索、直播问答、工作区安全、岗位匹配分析和模拟面试教练六类技能，并按当前任务自动选择；主界面“打开用户技能目录”可打开应用数据目录下的 `skills/` 文件夹。
- 普通对话提供普通对话、岗位匹配、模拟面试和面试复盘四种任务模式；模式会保存在历史对话中，不会改变事实边界，也不会自动虚构或写入个人经历。
- Windows 主窗口关闭后保留在系统托盘；托盘菜单提供显示主界面、打开提词面板和“退出软件并结束全部进程”。完整退出只清理 Electron/FunASR 运行进程，不删除 `userData` 中的知识库、记忆、配置或工作区。
- Windows 图标使用标准多尺寸 PNG-in-ICO 资源，同时用于应用窗口、托盘和安装快捷方式，避免旧版空白图标资源继续复用。

## 仍需设备验证或后续开发

1. 在实际 Windows 音频设备和 OBS 场景中继续验证共享音频选择行为。
2. 在当前轻量混合检索之上增加可选的本地 embedding 向量索引和跨文件实体图，不让向量服务成为基础功能的硬依赖。
3. 增加经用户确认的本地文件写入、修改和命令工具，并继续维持工作区边界检查。
4. 增加 OBS 显示器采集、窗口采集的实际测试页面。
5. 准备好 `transcriber/runtime` 和 `transcriber/models` 后运行 `npm run dist` 生成 NSIS 安装包；没有这些可选资源时仍可使用外接转录提供者。

## 连接说明

1. “API 地址”必须是接口地址，例如 `https://api.openai.com/v1` 或服务商给出的 `/v1` 兼容地址；密钥管理网页（例如带 `/keys` 的网页）不能填在这里。
2. 选择“OpenAI 官方 API”后填写官方 API Key；选择“环境变量自动连接 OpenAI”时，在启动应用前设置 `OPENAI_API_KEY`，应用会从进程环境读取，不在界面保存明文。
3. 选择“本机 Ollama”时，先启动 Ollama 并确认模型已下载，例如 `ollama pull qwen2.5:7b`，再点击“自动连接”。
4. 点击“测试连接”会先访问 `/models`；点击“自动连接”会按当前配置、环境变量、Ollama 的顺序尝试，并自动选择返回的第一个模型。
5. 当前 Codex/ChatGPT 桌面登录会话不能被第三方桌面应用直接复用。若要使用官方模型，请使用官方 API Key 或环境变量；也可以选择任意兼容接口或本机 Ollama。

## 本地中文转写

- 进入“直播模式”会先启动本地转写并请求系统声音权限，确认共享音频后才隐藏主窗口并打开悬浮提词面板。
- 本地模型随软件目录分发，首次启动需要等待模型加载；服务只监听 `127.0.0.1`，不会对局域网开放。
- 系统声音采集仍需在 Windows 共享选择器中选择窗口/屏幕并勾选共享音频；手动模式由用户划定完整录题区间，实时模式在约 1.6 秒连续静音后提交一段，最长语句和十分钟总时长都有限制。

## 转录提供者替换

默认协议见 `transcriber/README.md` 和 `transcriber/provider.json`。本地或外接实现只需提供 `GET /health` 和 `POST /transcribe`：后者接收 16 kHz PCM WAV 并返回 `{"text":"..."}`，也可附带 `rawText`、`punctuatedText` 和 `punctuationApplied`。用户可在应用 `userData/transcriber-provider.json` 放置覆盖配置；外接接口的密钥只通过该配置声明的环境变量注入，不要把密钥写入 JSON、源码或 Git。

## 公开发布与隐私

- API Key、知识库、长期记忆、聊天记录和用户技能都位于应用数据目录，不进入仓库或安装包源码。
- 发布前应运行语法检查、功能测试和凭据扫描；不要提交 `node_modules`、构建目录、模型权重、Python 运行时、`.env` 或本地提供者配置。
- 本项目代码许可证见 `LICENSE`；FunASR 与 Paraformer 模型属于第三方组件，署名和许可证见 `THIRD_PARTY_NOTICES.md`，本项目只提供适配和调用代码。

## 记忆与检索设计

当前实现参考 Mem0 的事实记忆思想、Letta 的持久化工作记忆思想、haiku.rag 的混合检索与文档来源思想，以及面试教练类开源项目的结构化追问流程，但保持本地 Electron 依赖轻量：

- `vault.json.files` 保存文件元数据、原文和带重叠的文本片段。
- `vault.json.memories` 保存用户明确陈述的稳定事实、偏好和工作流习惯。
- `vault.json.conversations` 保存最近 50 个会话快照。
- `AGENT_GUIDE.md` 规定直播会话、来源区分、回答上下文和持久化流程，直播模式实现必须遵循该指南。
- 每次提问按混合检索和结果去重排序，取前 10 个片段和最近 20 条记忆；结果带有检索方法与查询覆盖率标记，供模型判断上下文质量，不代表事实可信度。
- 文件和记忆支持单项删除；知识库保存原文和分块，当前使用本地词法检索，后续可替换为 embedding 向量索引而不改变持久化入口。

## 用户技能

用户技能示例：

```text
<应用 userData>\\skills\\my-skill\\SKILL.md
```

实际目录由主界面的“打开用户技能目录”按钮打开，不需要手动猜测路径。

文件可使用 YAML 风格的 `name`、`description`、`license`、`triggers` 元数据和 Markdown 正文。许可证不明的技能只会被本地只读加载，不会被复制或执行。
