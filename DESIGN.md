# Design System

## Direction
Quiet personal workstation for a solo livestream host. Dark graphite surfaces reduce glare. Amber marks active states and cool blue-gray carries secondary information.

## Tokens
The interface uses OKLCH tokens in `src/style.css`, restrained graphite surfaces, readable ink, and a restrained amber action color. Green is not used for primary actions or active states.

## Components
Top bar, settings sidebar, independently scrolling transcript and answer panes, and a compact protected prompt panel.
